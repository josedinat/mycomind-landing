What is cognitive continuity?

Cognitive continuity is the ability to pick up exactly where you left off on any topic — with full context of the decisions made, the questions still open, and how your thinking evolved to get there. It is the difference between an archive you can search and a memory you can question. Transcript tools and note apps give you the first one; My-CoMind is built for the second.
